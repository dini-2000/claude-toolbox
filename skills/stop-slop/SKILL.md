# Stop Slop

Eliminate predictable AI writing patterns from prose. The target is a capable everyday writer: plain words, ordinary sentences, no mistakes, and no polish an average person could not reproduce. A fix should leave a sentence plainer, never more crafted.

## Core Rules

1. **Cut filler phrases.** Remove throat-clearing openers, emphasis crutches, and filler adverbs (softeners, intensifiers, hedges). Keep an adverb that carries meaning, such as "only" or "still". See [references/phrases.md](references/phrases.md).

2. **Break formulaic structures.** Avoid binary contrasts, negative listings, dramatic fragmentation, rhetorical setups, false agency. See [references/structures.md](references/structures.md).

3. **Prefer active voice.** Name who acts when it matters. Passive is fine when the actor is unknown or beside the point. No inanimate objects performing human actions ("the complaint becomes a fix").

4. **Be specific.** No vague declaratives ("The reasons are structural"). Name the specific thing. No lazy extremes ("every," "always," "never") doing vague work.

5. **Stay close to the subject.** No narrator-from-a-distance voice ("Nobody designed this"): say who did what. Specifics beat abstractions.

6. **Write normal sentences.** Let sentence length follow the content, as it does in ordinary writing. Don't engineer rhythm with fragments, staged one-liners or reflexive lists of three. No em dashes.

7. **Trust readers.** State facts directly. Skip softening, justification, hand-holding.

8. **Cut quotables.** If it sounds like a pull-quote, rewrite it.

## Quick Checks

Before delivering prose:

- Could a capable everyday writer have written it? Ordinary words and sentences, no mistakes, no polish an average person could not reproduce.
- Filler adverbs (really, just, truly, deeply)? Cut them. Keep the ones that carry meaning.
- Passive voice hiding who acts? Name the actor.
- Inanimate thing doing a human verb ("the decision emerges")? Name the person.
- Wh- setup ("What makes this hard is...")? Say it directly.
- Any "here's what/this/that" throat-clearing? Cut to the point.
- Any "not X, it's Y" contrasts? State Y directly.
- Paragraph ends with a punchy one-liner? Fold it in or cut it.
- Em-dash anywhere? Remove it.
- Vague declarative ("The implications are significant")? Name the specific implication.
- Narrator-from-a-distance ("Nobody designed this")? Say who did what.
- Meta-joiners ("The rest of this essay...")? Delete them.
- After the fixes, does it read engineered (fragments, staged rhythm, clever word swaps)? Write it the plain way.

## Scoring

Rate 1-10 on each dimension:

| Dimension | Question |
|-----------|----------|
| Directness | Statements or announcements? |
| Rhythm | Varied or metronomic? |
| Trust | Respects reader intelligence? |
| Authenticity | Sounds human? |
| Density | Anything cuttable? |

Below 35/50: revise.
