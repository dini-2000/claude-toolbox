# House Style

This folder is House Style, a design kit for decks, paged PDF documents and one-off graphics: talks, teaching, pitches, reports,
letters, CVs, newsletters, posters, invitations and social posts. Read `SKILL.md` first: it is the instructions for
building with this kit (an HTML deck with its PDF and an editable PowerPoint that matches it 1:1, a document as a
print-ready PDF, a graphic as PNG, JPG or PDF). `README.md` is the reference for layouts, components, themes and
tools. Keep what you build in its own folder, outside the kit. On a new computer, run
`python3 tools/selftest.py --quick` once to check the kit works there.
